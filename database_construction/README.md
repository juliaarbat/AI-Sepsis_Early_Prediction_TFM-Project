# Database Construction

This folder contains the SQL scripts used to construct the analytical database for the early sepsis prediction project.

The scripts were developed and executed using DBeaver against the authorized clinical database environment. The original source data are not included in this repository due to privacy and institutional restrictions.

## Contents

- `*.sql`: ordered SQL scripts for constructing and validating the analytical tables.
- `00_SQL_EXECUTION_ORDER.md`: execution order and methodological notes.

## Execution

The SQL scripts should be executed in the order specified in:

```text
00_SQL_EXECUTION_ORDER.md
```

The final analytical table generated by this pipeline is:

```text
daily_sepsis_model
```

This table is subsequently exported as the input dataset for the Python analysis pipeline.

## Data Availability

The source clinical tables are not publicly available. Access is restricted to authorized users within the approved institutional environment.
